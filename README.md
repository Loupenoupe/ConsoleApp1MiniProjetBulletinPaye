# ConsoleApp1BulletinPaye

## Description

ConsoleApp1BulletinPaye est une application console développée en C#.

L'objectif du projet est de permettre la gestion et la génération d'un bulletin de paie à partir des informations concernant un salarié.

## Fonctionnalités

- Saisie des informations du salarié
- Calcul du salaire
- Calcul des différentes cotisations
- Calcul du salaire brut et du salaire net
- Affichage du bulletin de paie dans la console

## Technologies utilisées

- C#
- .NET
- Application console
